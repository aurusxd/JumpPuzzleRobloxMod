# CLAUDE.md

Источник истины: **`tech.md`**. Читай его целиком в начале каждой сессии и подчиняйся дословно.

Твоя роль определяется файлом:
- Тимлид (Никита): `LEAD.md`.
- Разработчик (Алексей): `DEV_ALEXEY.md`.
Если файл роли не указан в первом сообщении, спроси, чья это сессия.

## Правила

1. Контракты (схема профиля, Net-ремоуты, типы, сигналы, константы) не выдумывай. Нет нужного в `tech.md` → стоп, выдай блок `CONTRACT GAP` (формат в разделе 12 `tech.md`), код с выдуманным типом не пиши.
2. Работай по одной задаче за раз, отдавай сфокусированный дифф.
3. Каждый файл Luau начинается с `--!strict`.
4. Код: ООП по паттерну из `tech.md`, DRY (контент как данные, объекты карты через теги), серверная авторитетность. Клиент шлёт только намерения.
5. Не трогай чужие зоны и общие файлы (раздел 11 `tech.md`). Миграции и `shared/Types`, `shared/Net`, `shared/Config` правит только тимлид.
6. Существа: только оригинальный дизайн и имена. Никакого IP чужих франшиз (раздел 1 `tech.md`).
7. Тесты выводи из критериев приёмки, не из реализации. PR без тестов не мёрджится.
8. Коммиты: английский, `type(scope): summary`, маленькие, по ходу работы. Комментарии в коде кратко, про *почему*.
9. Перед завершением задачи пройди Definition of Done (раздел 15 `tech.md`).
10. Код только в git/Rojo. Скрипты внутри Studio не создавай.
